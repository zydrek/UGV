# Roteiro de Fases

| Etapa | Ficheiro | Objetivo |
| --- | --- | --- |
| Fase 1 | 01_fase_01_controle_motores.py | Validar o controlo básico dos motores. |
| Fase 2 | 02_fase_02_visao_opencv_basica.py | Capturar e processar imagem com OpenCV. |
| Fase 2.1 | 03_fase_02_1_detecao_arucos.py | Detetar marcadores ArUco. |
| Fase 3 | 04_fase_03_movimento_com_arucos.py | Associar a deteção de ArUcos ao movimento. |
| Fases 3.1 a 3.2.1 | 05 a 12 | Centralização, orientação, filtragem e mapa de navegação. |
| Fases 4 a 4.4.2 | 13 a 20 | Máquina de estados, cruzamentos, gimbal e planeamento de trajetos. |
| Fase 5 | 21_fase_05_codigo_final.py | Integrar os componentes no fluxo final de navegação. |

Os ficheiros estão numerados para refletir a sequência recomendada de experimentação. Execute cada etapa apenas depois de validar os requisitos de hardware e software das fases anteriores.
